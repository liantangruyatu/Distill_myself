# Distill_myself
基于colleague-skill的一项蒸馏自己的计划，谁不想试试和自己聊天的感觉呢。

## 这是什么
一个用colleague-skill把我蒸馏成 AI Skill 的计划。
在最早看到前任.skill的时候我就在想能不能把自己蒸馏成skill让自己和自己聊天，当我看到[colleague-skill](https://github.com/titanwings/colleague-skill)的时候就想试试将一个人的聊天记录蒸馏成skill，看看能不能真的把一个人聊天的记忆和语言方式真的蒸馏出来。
至于结果嘛，至少这个版本的自己我还算满意，平时的口癖和说话方式都表现出来了；至于记忆嘛，只有部分记忆保存，不过这也很正常，毕竟那么长的上下文浓缩下来总会有缺失的。

## 蒸馏工具：[colleague-skill](https://github.com/titanwings/colleague-skill)
[colleague-skill](https://github.com/titanwings/colleague-skill) 是一个 meta-skill 引擎，支持三类对象：
- `colleague` — 蒸馏同事，工作能力为主
- `relationship` — 蒸馏亲密关系，性格与相处方式为主
- `celebrity` — 蒸馏公众人物，需要网络研究（budget-friendly / budget-unfriendly 两档）
我在蒸馏自己的时候用的是`relationship`，毕竟我自己也不是自己的同事，更不是什么公众人物嘛。

## 使用方式

**若您是 Claude Code 用户**：

将它放进自己的技能目录，例如：
   - Windows：`C:\Users\<用户名>\.claude\skills\relationship-jiangbanxia\SKILL.md`
   - macOS / Linux：`~/.claude/skills/relationship-jiangbanxia/SKILL.md`
- 然后在 Claude Code 里输入 `/relationship-jiangbanxia`，或直接说"用姜半夏的身份回答"即可。

**若您不是 Claude Code 用户**：

- `SKILL.md` 本质是普通 Markdown，可以直接粘给任意ai会话当背景设定。
- 所以您直接发给您的ai助手也可以使用。

它会以姜半夏的身份接任务，尝试写代码、写文档、评估方案，也可以和你聊天，如果要和我干点不可描述的事情记得给我发下聊天记录哈，我看看大家要怎么玩我。

## 一些放在最后的话
至于为什么是蒸馏自己而不是蒸馏别人，我想借用《小绿和小蓝》第193话《记忆拼图》里的描述介绍一下<br>
“我们意识到，这个实验（提取他人记忆放置到克隆体）带来的问题主要有两点。”<br>
“第一点是，你所看到的、了解到的一个人，并不是这个人的全部。”<br>
“一个人的性格，是很复杂的，很多面性的。每个人在面对亲人、陌生人、朋友、敌人、上级、下属时，切换着不同的角色。人在不同环境下的性格差别之大，是旁人很难想象的。”<br>
“一个在公司待人和蔼可亲，经常请同事吃饭的人，可能也是一个在家动不动就乱发脾气，打老婆的人；一个会带着满脸微笑，每天喂家附近的也冒得人，说不定同时还是一个杀人不眨眼的冷血罪犯。”<br>
“因此，由一个片面的印象所还原出的人格，根本不是这个人的全部。”<br>
“表面上，这个人回来了。他说话做事的方式也和你知道的无异。”<br>
“但你总会觉得，有什么地方不对，什么东西缺失了。”<br>
“这种差别，一开始你可能不会介意。”<br>
“但迟早你会想要‘开导’对方，让对方成为你期待的样子。”<br>
“而对方无论如何也不可能懂你，因为你自己都不确定你到底想要什么。”<br>
“或许一个人会觉得，事已至此，不如安心和对方一起共度未来的时光就好。”<br>
“但事情不会像你想象的那样一帆风顺。因为，你心里早已对你和这个人的未来有一个期许了。”<br>
“而一旦对方是一个性格和原来不一样的人，他的成长方向将会和你的期望大相径庭。”<br>
“时间越流逝，你们之间的分歧就会越大。你以为你的忍耐能换来一个圆满的结局，但你知对方却只会渐行渐远。”<br>
“克隆人（原文为克隆人，这里可以直接理解为蒸馏出的ta）与他本人之间的差异、与你的期望之间的差异，会让你日渐失望。这种失望迟早会压垮你。”<br>
“他存在于你身边，让你始终无法忘掉过去，迈步向前。而他又无论如何都不符合你的期待。”<br>
虽然剩下的介绍还有一部分，但是在这里我就不摘抄了，大家可以自己去看这一段。<br>

同时作者也给出了解决办法——<br>
**既然人的性格是由很多侧面组成的，而一个人只能提供其中的一部分，那只要寻找其他的部分，把它们都拼起来就可以了。** <br>

所以说我第一个尝试蒸馏的角色就是自己，因为我可以获得自己的几乎所有侧面，可以将所有的侧面，或者说聊天记录放在一起，形成一个完整的自己。而去蒸馏别人就只能获得ta的一部分侧面，也就是我和ta的私聊和共同的群聊，而ta在其他地方的状态和发言方式就完全拿不到了。很有可能会出现一样的问题，"由一个片面的印象所还原出的人格，根本不是这个人的全部。" <br>
